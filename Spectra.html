Spectra.

An API client for the agentic era. A native desktop app for macOS and Windows with a Rust core and an MCP server built in, so you and your AI agent work the same requests, in the same workspace, with zero telemetry.

Download for macOS & Windows Read the source
  • Rust
  • Tauri v2
  • React 19
  • MCP
  • MIT
(01) Capabilities

Everything an API client does, plus an agent.

01

Core client

  • Every HTTP verb, from GET to OPTIONS
  • Headers, params, JSON, form and raw bodies
  • Monaco response viewer for JSON, XML, HTML and YAML
  • Workspaces and drag-and-drop collections
  • Environments with secret masking
  • Request history with replay and saved responses
02

Interface

  • Native desktop window, with an overlay title bar on macOS
  • System, Light, Dark and Crimson themes
  • VS Code-grade syntax highlighting
  • Resizable sidebar, request, response and console panes
03

Authentication

  • OAuth 2.0: auth code, client credentials, PKCE
  • Bearer, Basic and API key at any scope
  • AWS Signature v4, Hawk and Digest
  • Set auth once, override per folder or request
04

AI-native (MCP)

  • MCP server ships as a sidecar, zero config
  • 60+ tools to read workspaces, send and analyse
  • Works with Claude Desktop, Cursor, Windsurf and others
  • Agents can even screenshot the app
05

Performance

  • Rust handles HTTP, SQLite storage and crypto
  • Large JSON is formatted off the main thread
  • Virtual scrolling for huge request trees
  • About 105 KB gzipped on the front end
06 · Not yet

On the list

  • Team workspaces and cloud sync
  • Mock servers
  • A CI test runner
  • gRPC, GraphQL and WebSocket
  • Linux builds

Spectra gives up team features and, for now, Linux in exchange for native desktop builds with the MCP server in its core rather than bolted on. Postman and Insomnia are collaboration platforms. Spectra is a workbench for one human and their agent.

(04) Build

Four commands to your own copy.

# 1. Clone the repository
git clone https://github.com/rishabhyadavm07/Spectra.git
cd Spectra

# 2. Install frontend dependencies
npm install

# 3. Run in development mode (hot reload)
npm run tauri dev

# 4. Build for production
npm run build:mac
