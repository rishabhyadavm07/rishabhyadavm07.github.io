Capabilities

Everything you need to test an API

🚀
Core API Client
  • Full HTTP support — GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS
  • Headers, query params, JSON/form/raw body editor with syntax highlighting
  • Monaco-powered response viewer with JSON/XML/HTML/YAML formatting
  • Workspaces & collections with drag-and-drop organization
  • Environments with secret masking and per-environment overrides
  • Automatic request history with replay and saved responses
🎨
Beautiful Interface
  • Native macOS feel — overlay title bar, transparent window
  • Adaptive themes — System, Light, Dark, and Crimson
  • Full VS Code-grade syntax highlighting via Monaco Editor
  • Resizable panels for sidebar, request/response split, and console
🔐
Authentication
  • OAuth 2.0 — Authorization Code, Client Credentials, PKCE
  • Bearer Token, Basic Auth, API Key at any scope
  • AWS Signature v4, Hawk, and Digest built-in
  • Auth inheritance — set once, override per-folder or per-request
🤖
AI-Native (MCP)
  • Built-in MCP server ships as a sidecar binary — zero config
  • 60+ MCP tools to read workspaces, send requests, analyze responses
  • Works with Claude Desktop, Cursor, Windsurf, or any MCP client
  • Agents can even take GUI screenshots of the app
⚡
Performance
  • Rust backend — HTTP execution, SQLite storage, crypto run natively
  • Web Worker formatting keeps large JSON off the main thread
  • Virtual scrolling handles massive request trees without lag
  • ~105 KB gzipped frontend bundle

Spectra trades team features and cross-platform reach for a native macOS-first build and an MCP server built into the core — not bolted on. Where Postman and Insomnia are collaboration platforms, Spectra is optimized to be driven by both you and your AI agent, locally, with zero telemetry.
